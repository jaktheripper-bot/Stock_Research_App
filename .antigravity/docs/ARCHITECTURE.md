# System Architecture & Technical Knowledge Base

## 1. Core Architectural Directives
* **Zero-Hallucination Data Integrity:** Synthetic or AI-estimated financial metrics (P/E, Market Cap, 52-Week Range) are strictly prohibited. The system must enforce hard stops when live exchange quotes fail[cite: 2].
* **Two-Tier Caching & Delta Gating:** Expensive qualitative LLM regenerations trigger only on material events: price moves >= 5%, new BSE filings, or a report age > 14 days[cite: 2].

## 2. Scrip Resolution & Data Ingestion
* **5-Tier BSE Resolution:** Queries map to 6-digit BSE codes via: (1) Direct 6-Digit Code, (2) `dynamic_aliases.json`, (3) Static `PRIMARY_BSE_MAP`, (4) Active Master Universe `bse_scrips_cache.json`, and (5) Just-In-Time Gemini Grounded Search[cite: 2].
* **Ingestion, SmartAPI EOD & Official BSE JSON Routing (`YFINANCE_FALLBACK=0` Production Default):** Primary equity data is fetched via Angel One SmartAPI (`AngelOneGateway` live quotes, Level-2 depth, dynamic scrip search via `search_scrip_token`, and 1-year `ONE_DAY` historical EOD candles via `get_eod_summary` computing EOD price, 52W High/Low, 50-DMA, and 200-DMA) paired with sub-second Official BSE Direct JSON APIs (`getScripHeaderData/w` + `ComHeader/w` in `fetch_bse_exchange_data`) and deterministic quantitative extraction from archived statutory filing dossiers (`extract_fundamentals_from_report_text`). Production `core/config.py:yfinance_fallback_enabled()` defaults to `False` (`YFINANCE_FALLBACK=0`), keeping `yfinance` strictly opt-in (`YFINANCE_FALLBACK=1`) and returning standardized sentinels (`—`, `NM`, `BFSI`) rather than guessing when fields are unavailable.

## 3. Persistence & AI Routing
* **Fail-Closed Primary Database & Explicit Local SQLite Mode (`AuthoritativeDatabaseUnavailable`):** Production and any runtime with `SUPABASE_DB_URL` configured bind exclusively to Supabase PostgreSQL; if PostgreSQL is unreachable or in failure cooldown, `_get_raw_connection()` and `init_db()` raise `AuthoritativeDatabaseUnavailable` (mapped to `HTTP 503 Service Unavailable` in `web/main.py`) with zero split-brain fallback writes to container-local SQLite (`FORCE_LOCAL_SQLITE` and `TESTING` overrides are ignored when `is_hosted_production_runtime()` is `True`). Local development and hermetic test suites with `FORCE_LOCAL_SQLITE=1` or unconfigured `SUPABASE_DB_URL` use WAL-mode SQLite (`reports.db`).
* **Multi-Provider Failover, Vertex AI Postpay SSE Streaming & Perplexity Circuit Breaker:** When `GOOGLE_GENAI_USE_VERTEXAI=true`, `google-genai` routes through Google Cloud Vertex AI Postpay (`client.vertexai == True`) using deterministic model selection (`gemini-3.8-flash` -> `gemini-3.7-flash` -> `gemini-3.5-flash` for full grounded synthesis and `gemini-3.5-flash-lite` for surgical/look-through narratives, bypassing unsupported `models.list()` and `service_tier="flex"` parameters) and **SSE streaming (`stream_genai_with_fallback`, `VERTEX_AI_POSTPAY_GROUNDED_SSE`)** across both cohort equity synthesis (`synthesize_batch_stock_reports`) and mutual fund forensic audits (`synthesize_fund_forensic_narrative`), eliminating unary `504` / `60s` socket timeouts on grounded/long syntheses. On standard AI Studio keys, the daily 15-stock cohort submits via Gemini Batch API (`client.batches.create`, 50% discount) with Gemini Flex Inference (`service_tier="flex"`, 50% discount) fallback. If Google API exhausts retries, synthesis fails over to the Perplexity Agent API (`/v1/responses`, streaming then non-streaming) guarded by a session-scoped circuit breaker (`_PERPLEXITY_CIRCUIT_OPEN`, resettable via `reset_perplexity_circuit_breaker()`) that trips immediately on `401/402/403`, `restricted_api_key`, or `insufficient_quota` so remaining batch items fail fast without repeat timeout amplification[cite: 2].
