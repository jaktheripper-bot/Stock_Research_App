# SEBI Regulatory Guardrails & Compliance

## 1. Legal Classification
* This platform operates under the SEBI Safe Harbor as an automated data publisher and software utility, not as a registered Investment Adviser (RIA) or Research Analyst (RA)[cite: 5, 6].
* **Zero User Personalization:** The system must never collect user net worth, risk tolerance, or portfolio holdings to generate tailored advice[cite: 6].

## 2. Output Constraints
* **No Prescriptive Verdicts:** The system is strictly forbidden from generating explicit BUY, HOLD, or SELL recommendations[cite: 5]. 
* **Zero Forward-Looking or Actionable Guidance:** The report concludes strictly after Pillar 7. Forward-looking guidance, actionable advice, conclusion summaries, and monitorable targets are strictly forbidden to ensure full immunity under SEBI Safe Harbor rules.
* **Descriptive Diagnostics Only:** Outputs must be framed as factual health scores (e.g., Moat: Wide, Governance: Clean, Diagnostic: Structural) based on public exchange disclosures[cite: 5, 6].

## 3. Immutable Notice
* Every UI view and exported document must append this exact disclaimer: "Disclaimer: This report is automatically generated by an AI research assistant using public BSE disclosures and search grounding. It is intended strictly for informational and educational auditing purposes and does not constitute financial or investment advice."[cite: 6].
