## Production scope and remaining integration

This is a generation handoff, with the inventory's exact web/static/img folder tree. The live application's files, inline SVG sprites, template image placements and theme mappings have not been changed. Its older canonical logo files therefore still require the approved replacements during implementation. Hero and manifesto files are not currently referenced by the application; placing them in a folder alone is not a completed UI integration.

The inventory's nine-domain colour table is used for this artwork. core/brand/visual_identity.py still contains older seven-domain mappings; reconcile those during implementation, then validate light/dark rendering and run the repository's website verification gates.

All new AI rasters are conceptual Indian landscapes and architecture, not documentary locations, events or company assets. The real native dimensions and exact prompts are in raster-generation-manifest.json. Large PNG exports are labelled resampled; the native sources are retained. Functional SVGs are code-built vectors with currentColor and no bitmap embeds; themed preview colours are examples, not blanket contrast certification.

The locked logo geometry is preserved. Canonical wordmark and stacked canvases have been padded to 800 × 200 and 600 × 600 without stretching the artwork. Wordmark SVGs retain live text: font licensing and outlining remain required for portable release artwork. Favicon source uses the approved high-contrast tile; rounded transparent corners remain in PNG.
